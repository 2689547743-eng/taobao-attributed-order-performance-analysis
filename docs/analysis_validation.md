# 分析验证报告

## 总体评估：可在明确限制下分享

本项目的聚合计算、订单粒度和主要金额已完成代码复算。它适合展示数据准备、质量检查、指标设计和审慎的运营排查思路；不适合用于财务结算、广告 ROI 或因果效果判断。

## 已验证项目

- 7 份月度原始文件字段结构一致，合并后为 31,036 条商品订单明细。
- SKU 标签维表按商品 ID 去重后有 65 条记录；明细标签匹配率为 100%，不存在标签组合冲突。
- 商品订单明细、订单汇总、标签汇总和月度汇总的归因付款金额均可对账到 4,072,492.00。
- 订单状态分类、主失效订单率分母、零付款明细率分母和推广位样本门槛均在 `docs/metric_definitions.md` 与代码中明确实现。
- 只有相邻且均为完整月的月份计算普通环比；2020-11 与 2021-03 的环比为空值。

## 必须随结果披露的限制

- 原始行是商品订单明细；分组后的订单数不能横向相加为总订单数。
- `付款金额`仅代表归因付款金额；结算、佣金、利润和 ROI 不可用。
- 缺少曝光、完整点击量和成本；推广位比较只能描述归因规模和订单风险，不能表述为投放效率或因果效果。
- 混合状态订单不进入主失效订单率分母；“非失效”不等于最终完成成交。
- 原始数据不公开上传。仓库中仅保留聚合输出、图表、代码和复现说明。
