# 运营建议：仅作为排查与测试方向

## 1. 先完成 2021-05 零付款明细的专项核验

5 月零付款明细率为 23.72%，显著高于 4 月的 3.96%；其中睡眠标签有 1,846 条零付款明细。应分层抽查睡眠标签的原始订单记录、付款金额、订单状态和提取字段，确认这是业务状态、字段定义还是数据提取异常。

建议产出：明确零付款的业务含义、记录抽查规则，并在后续看板中把零付款明细率与订单状态分开呈现。

## 2. 优先复盘高规模且高失效风险的睡眠标签与推广位

睡眠标签有 1,140,424.22 的归因付款金额、12,338 个归因订单和 7.56% 的主失效订单率，高于整体 6.86%。`VesleepI1`、`VsleepI31`、`TsleepI6` 的归因付款金额均超过 154,000，且主失效订单率为 8.08%–9.05%。

建议按 SKU、订单类型、零付款标记和订单状态复盘这些对象，定位规模最大的风险切片。此建议是风险排查优先级，不是减少或增加推广预算的结论。

## 3. 将低失效的大样本推广位作为后续测试的对照参考

`VproI524` 与 `VproI526` 均满足样本门槛，归因订单数分别为 1,245 与 1,241，主失效订单率分别为 2.81% 与 4.27%。若未来取得曝光、完整点击和成本数据，可将它们作为创意、商品组合或落地页小范围测试的参考对象。

在未取得这些字段前，不把它们称为“高效”推广位，也不计算 ROI 或建议加预算。

## 验证条件

所有测试都应预先声明对象、时间窗、样本门槛、主指标和护栏指标。建议至少记录曝光、完整点击、成本、结算结果，以及归因订单/失效订单/零付款明细的口径，避免将订单结构差异误读为优化效果。
