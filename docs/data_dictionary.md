# 数据字典

## 源数据表

### 月度归因订单文件

每一行代表一条归因商品订单明细，不一定对应一个独立订单；同一淘宝订单编号可以包含多个商品行。

| 源字段 | 项目用途 | 说明 |
|---|---|---|
| 点击月份 / 点击日期 / 点击时间 | 归因时间 | 衍生 `click_month` 与 `is_complete_month` 以支持时间范围判断。 |
| 创建时间 / 付款时间 / 淘宝付款时间 | 订单时间 | 仅用于描述性时间检查，不假设其构成严格的漏斗顺序。 |
| 结算时间 | 不使用 | 本提取数据中为空。 |
| 商品ID | SKU 主键 | 用于关联和 SKU 聚合。 |
| 商品标题 | 展示字段 | 同一商品 ID 存在多个促销标题版本，不能作为 SKU 主键。 |
| 商品数量 / 商品单价 | 商品数量与标价 | 用于衍生 `list_amount`。 |
| 淘宝订单编号 | 订单主键 | 用于生成 `orders_clean.csv`。 |
| 淘宝子订单号 | 不使用 | 本提取数据中为空。 |
| 订单状态 | 风险描述字段 | 汇总为订单级状态分类。 |
| 订单类型 | 订单分组字段 | 用于描述性分层。 |
| 付款金额 | 归因付款金额 | 不是最终营收、结算收入或利润。 |
| 结算金额 / 佣金金额 | 不使用 | 本提取数据中为空。 |
| 佣金比率 | 源字段 | 为可追溯性保留；佣金金额为空，不能据此推算佣金。 |
| 推广位ID / 推广位名称 | 推广位主键 | 用于推广位归因表现分析。 |
| 成交平台 | 平台描述字段 | 用于描述性分层。 |

### SKU 标签文件

| 源字段 | 项目用途 |
|---|---|
| 商品ID | 与订单明细关联的主键 |
| 商品标题 | 仅作参考标题 |
| 一级标签 | 一级商品分类 |
| 二级标签 | 二级商品分类 |

## 生成的数据集

| 文件 | 粒度 | 用途 |
|---|---|---|
| `order_lines_clean.csv` | 一条归因商品订单明细 | 商品、标签、推广位、归因付款金额和明细状态分析 |
| `orders_clean.csv` | 一个淘宝订单编号 | 订单数、多商品订单、订单状态分类和付款时长分析 |
| `sku_dimension.csv` | 一个商品 ID | 稳定的 SKU—标签映射 |

技术字段别名保留英文，以便代码和后续 SQL 分析复现；字段含义以本中文数据字典为准。

## 关键衍生字段

| 字段 | 所在表 | 含义与使用规则 |
|---|---|---|
| `list_amount` | `order_lines_clean.csv` | `商品数量 × 商品单价`，即明细标价金额。 |
| `payment_to_list_ratio` | 明细表、订单表 | 在汇总层级以“归因付款金额之和 / 标价金额之和”重新计算，不对明细比例做简单平均。 |
| `is_zero_payment_line` | 明细表 | `付款金额 = 0` 的明细标记，用于零付款明细率。 |
| `is_invalid_line` | 明细表 | `订单状态 = 已失效` 的明细标记；不等同于订单级失效判断。 |
| `order_status_classification` | `orders_clean.csv` | `invalid_order`：订单所有明细均为已失效；`non_invalid_order`：所有明细均为已付款或已收货；其余为 `mixed_status_order`。 |
| `order_sku_key` | 明细表 | `淘宝订单编号 + 商品ID` 的组合定位键，不是原始子订单号。 |
| `order_sku_line_sequence` | 明细表 | 同一 `order_sku_key` 内按原始读取顺序生成的序号；用于保留重复组合。 |
| `order_line_key` | 明细表 | `order_sku_key + 行序号` 的唯一技术行键，仅用于定位和复现，不应解释为业务子订单号。 |
