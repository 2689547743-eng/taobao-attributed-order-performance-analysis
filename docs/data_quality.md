# 数据质量检查说明

`src/build_datasets.py` 会生成两类文件：

- 供阅读的中文报告：`outputs/data_quality/data_quality_report.md`；
- 供代码读取的结构化摘要：`outputs/data_quality/data_quality_summary.json`。

脚本检查以下内容：

- 7 份月度订单文件是否具有一致的 26 个字段；
- 各源文件的日期覆盖范围和是否为完整月；
- 是否存在完全重复的商品订单明细；
- 同订单/同 SKU 重复组合及多商品订单；
- 混合状态订单；
- 每个源字段的缺失率；
- 数值范围，以及付款金额是否高于标价金额；
- 零付款明细和零付款订单；
- SKU 标签重复、标签冲突与订单明细匹配率；
- 点击至付款时长，以及是否存在负时长。

## 本次核验结果

本次以 `淘宝订单数据by点击日期` 内的 7 份月度工作簿和 `淘宝sku标签.xlsx` 为事实来源。生成结果见 `outputs/data_quality/`。

| 项目 | 结果 |
|---|---:|
| 商品订单明细 | 31,036 |
| 淘宝订单编号 | 27,521 |
| 商品 ID | 65 |
| 推广位 ID | 253 |
| 完全重复明细 | 0 |
| 重复“订单编号 + 商品 ID”组合 | 42 |
| 多 SKU 订单 | 2,854 |
| 混合状态订单 | 163 |
| 零付款商品订单明细 | 2,489 |
| SKU 标签匹配率 | 100.00% |

2020-11 覆盖 17 / 30 天，2021-03 覆盖 22 / 31 天；两者标记为不完整月份。2020-12、2021-01、2021-02、2021-04 和 2021-05 为完整月份。

所有月度文件的 26 个源字段结构一致。`结算时间`、`淘宝子订单号`、`结算金额` 和 `佣金金额` 的缺失率均为 100%，因此相关财务分析被明确排除。

该报告描述的是数据质量，不代表已经证明字段的商业含义。输出业务结论前，项目负责人必须抽查原始记录，并确认指标口径。
