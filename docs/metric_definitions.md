# 指标口径定义

## 1. 适用范围与确认事项

本文件定义本项目中用于商品结构、推广位表现和订单失效风险分析的指标。数据源粒度是“归因商品订单明细”，不等同于独立订单。订单级指标一律按 `淘宝订单编号` 去重或汇总。

已确认的业务口径如下：

- 规模金额统一使用所有商品订单明细的 `付款金额` 之和，并称为**归因付款金额**；它不代表最终营收、结算收入或利润。
- 失效订单率的主口径排除 `mixed_status_order`；只以完全失效订单和非失效订单构成分母。
- 零付款仅在商品订单明细粒度计算，分母为全部商品订单明细；不计算零付款订单率。
- 原始 `淘宝子订单号` 为空。重复的“订单编号 + 商品 ID”组合不删除；技术上用组合键和行序号定位，但不能把它们解释为真实子订单号。
- 2020-11 和 2021-03 不是完整月，不参与普通月度环比；如需比较，仅可单独展示或改用日均指标，并明确说明。

## 2. 粒度、时间与订单状态

| 项目 | 规定 |
|---|---|
| 商品 / 推广位 / 标签金额类指标 | 商品订单明细粒度汇总。 |
| 订单数与订单风险类指标 | 先按 `淘宝订单编号` 识别订单，再在相应分组内去重计数。一个订单可出现在多个 SKU 或推广位分组中，因此分组订单数不能横向相加为总体订单数。 |
| SKU 主键 | 使用 `商品ID`；商品标题只用于展示。 |
| 明细时间 | 使用该明细的 `点击日期` / `click_month`。 |
| 订单级时间 | 使用订单内最早的点击时间及对应月份（`order_first_click_time` / `order_click_month`）。当前有 4 个订单跨点击月份，月度订单分析须在说明中披露该分配规则。 |
| 完整月 | 仅 2020-12、2021-01、2021-02、2021-04、2021-05 可参与普通月环比。 |

### 订单状态分类

| 分类 | 判断规则 | 在失效订单率中的处理 |
|---|---|---|
| `invalid_order` | 一个订单的所有明细状态均为“已失效” | 计入分子和分母 |
| `non_invalid_order` | 一个订单的所有明细状态均为“已付款”或“已收货” | 仅计入分母 |
| `mixed_status_order` | 同一订单同时存在上述不同状态或其他组合 | 单独展示，不计入主口径分子或分母 |

“非失效”只表示没有被归为完全失效，**不等同于最终完成成交**。

## 3. 核心指标

### 3.1 归因订单数

| 项目 | 定义 |
|---|---|
| 业务含义 | 在分析范围或分组内被归因到至少一条商品明细的不同订单数量。 |
| 公式 | `COUNT(DISTINCT 淘宝订单编号)` |
| 统计粒度 | 订单级；按 SKU、标签或推广位拆分时，在每个分组内独立去重。 |
| 分母 | 无。 |
| 边界 | 跨 SKU、跨推广位的订单会同时进入多个分组，故不能把各分组订单数相加作为总体订单数。 |

### 3.2 归因付款金额

| 项目 | 定义 |
|---|---|
| 业务含义 | 归因商品订单明细的付款金额规模。 |
| 公式 | `SUM(付款金额)` |
| 统计粒度 | 商品订单明细。 |
| 分母 | 无。 |
| 异常处理 | 付款金额为 0 的明细保留并参与求和。当前数据未发现负付款金额。 |
| 边界 | 包含各订单状态的明细；仅称为归因付款金额，不代表真实营收、结算、佣金或利润。 |

### 3.3 商品件数

| 项目 | 定义 |
|---|---|
| 业务含义 | 归因商品订单明细中的商品数量规模。 |
| 公式 | `SUM(商品数量)` |
| 统计粒度 | 商品订单明细。 |
| 分母 | 无。 |
| 异常处理 | 不删除重复的“订单编号 + 商品ID”组合；每一条原始明细均被保留。 |

### 3.4 付款 / 标价比

| 项目 | 定义 |
|---|---|
| 业务含义 | 归因付款金额相对于明细标价金额的比例，用于描述折价程度。 |
| 公式 | `SUM(付款金额) / SUM(商品数量 × 商品单价)` |
| 统计粒度 | 商品订单明细汇总层；不对单行比例做简单平均。 |
| 分母 | `SUM(商品数量 × 商品单价)`。 |
| 异常处理 | 若分母为 0，结果记为缺失值，不计算。 |
| 边界 | 它不是毛利率、折扣由某项促销造成的证明，也不能说明价格策略的因果效果。 |

### 3.5 失效订单率（主口径）

| 项目 | 定义 |
|---|---|
| 业务含义 | 在状态可明确判定的订单中，完全失效订单的占比。 |
| 公式 | `invalid_order 数 / (invalid_order 数 + non_invalid_order 数)` |
| 统计粒度 | 订单级；在每个 SKU、标签、推广位或时间分组内先对订单编号去重。 |
| 分母 | 完全失效订单数与非失效订单数之和。 |
| 异常处理 | `mixed_status_order` 不进入分子或分母，另列“混合状态订单数”。若分母为 0，结果记为缺失值。 |
| 边界 | 该比例反映数据提取中的订单状态结构，不能单独归因于商品、推广位或某项运营动作。分组中可参与计算的订单数必须同时展示。 |

### 3.6 零付款商品订单明细率

| 项目 | 定义 |
|---|---|
| 业务含义 | 付款金额为 0 的商品订单明细占全部商品订单明细的比例。 |
| 公式 | `COUNT(付款金额 = 0 的明细) / COUNT(全部商品订单明细)` |
| 统计粒度 | 商品订单明细。 |
| 分母 | 当前分析范围或分组内的全部商品订单明细数。 |
| 异常处理 | 若分母为 0，结果记为缺失值。零付款明细不删除。 |
| 边界 | 不将其称为零付款订单率；一个订单可有多条商品明细，且当前数据中不存在订单归因付款金额为 0 的订单。 |

### 3.7 推广位活跃天数

| 项目 | 定义 |
|---|---|
| 业务含义 | 某推广位在数据中出现归因商品订单明细的不同点击日期数。 |
| 公式 | `COUNT(DISTINCT 点击日期)`，按推广位 ID 计算。 |
| 统计粒度 | 推广位 × 点击日期。 |
| 分母 | 无。 |
| 边界 | 它是“在归因订单数据中有记录的天数”，不是投放天数、曝光天数或实际资源占用天数。 |

### 3.8 推广位日均归因付款金额

| 项目 | 定义 |
|---|---|
| 业务含义 | 推广位在有归因订单记录的活跃日内，平均每天的归因付款金额。 |
| 公式 | `推广位归因付款金额 / 推广位活跃天数` |
| 统计粒度 | 推广位。 |
| 分母 | 推广位活跃天数。 |
| 异常处理 | 活跃天数为 0 时记为缺失值。 |
| 边界 | 不能替代按完整自然日、曝光或成本计算的投放效率，也不能用于 ROI 判断。 |

### 3.9 归因付款金额份额

| 项目 | 定义 |
|---|---|
| 业务含义 | 某个互斥分类（如一级标签）或单个对象贡献的归因付款金额占选定分析范围的比例。 |
| 公式 | `分组归因付款金额 / 同一分析范围内的归因付款金额` |
| 统计粒度 | 商品订单明细汇总层。 |
| 分母 | 同一筛选范围的归因付款金额。 |
| 边界 | 按互斥 SKU 或标签维度时可以加总；不同推广位如对应同一订单的不同明细，须直接以明细金额计算，不能从订单数份额推断。 |

## 4. 推广位比较的样本规则

推广位主排序、规模—风险矩阵和建议候选对象须同时满足：

- 归因订单数不少于 **30**；
- 推广位活跃天数不少于 **7**；
- 展示失效订单率时，同时显示其可判定状态订单数（失效 + 非失效）。

不满足条件的推广位可以保留在明细表中，但标记为“小样本，不参与主比较”，不基于其排名提出资源调整建议。该规则用于降低少量大单或短期记录造成的误判，并不代表统计显著性检验。

## 5. 计算与展示规则

- 金额保留到分，展示时可按千分位或万元转换，但必须标注单位；比例展示为百分比时保留 1–2 位小数。
- 月度环比仅对完整且连续的月份计算：2020-12→2021-01、2021-01→2021-02、2021-04→2021-05。不得跨越 2020-11 或 2021-03 的缺失日期直接计算普通环比。
- 分析任一分组的失效订单率时，同时展示：归因订单数、可判定状态订单数、混合状态订单数和失效订单数。只看失效率排名不构成优先级判断。
- 比较商品或推广位时，先看规模（归因付款金额、归因订单数），再看风险（失效订单率、零付款商品订单明细率）；没有成本、曝光和完整点击量，不能把结果称为投放 ROI 或转化效率。

## 6. 不做的指标

- 不计算 ROI、利润、实际结算收入、佣金收入、点击率或完整转化率；对应的成本、曝光、完整点击和有效结算字段缺失。
- 不计算复购率、RFM、留存、客单用户价值或用户画像；数据没有用户 ID。
- 不把“已付款”直接表述为最终成交，也不把未验证建议表述成已实现的增长效果。
